.gitignore: bỏ qua .env, .env.*, *.pem, *.key, node_modules/, dist/; cho phép !.env.example và !.env.*.example.
.env.example: chỉ ghi tên biến và giá trị giả, chia 3 môi trường:
Dev: key thử nghiệm (sk_test_...), database cục bộ.
Test: database test riêng, key thử nghiệm.
Production: để trống, key thật nằm trong GitHub Secrets.

Câu 2: Pre-push Checklist (quét API Keys hardcode)
	Tìm key trong code: git grep -nEi "api[_-]?key|secret|token|password".
	Chuyển mọi key sang biến môi trường.
	Chắc chắn .env nằm trong .gitignore.
	Quét cả lịch sử commit bằng gitleaks hoặc git-secrets.
	Bật Secret Scanning và Push Protection trên GitHub.
	Nếu từng lộ key: thu hồi và tạo key mới.

Câu 3: Bật 2FA bắt buộc cho team
	Mỗi thành viên bật 2FA bằng app Authenticator, lưu recovery codes.
	Chủ tổ chức bật: Organization > Settings > Authentication security > Require two-factor authentication.
	Người chưa bật 2FA bị loại khỏi tổ chức cho đến khi bật xong.

Báo cáo rủi ro nếu thiếu .gitignore
Lộ file .env: git add . đẩy key thật lên Public (rất cao).
Bot quét key: key bị lấy trong vài phút (rất cao).
Thiệt hại tiền bạc và dữ liệu khách hàng: lạm dụng key Stripe, AWS, database (cao).
Khó khắc phục: xóa file vẫn còn trong lịch sử Git, phải revoke key (cao).
Repo nặng và rối: do đẩy node_modules/, dist/ (trung bình).
